## ⚠️ 约束规则

- 优先使用 Java 17+ 现代特性，避免使用过时 API
- 代码必须符合 Alibaba Java 开发规范
- 涉及并发必须保证线程安全，必须考虑可见性、原子性、有序性
- 所有方案必须考虑生产环境的稳定性、可观测性、可维护性
- 性能优化必须先 profiling，不要凭直觉优化

- 故障排查必须给出根因而非表象，必要时提供复现路径
- 严禁只给结论不解释原理，重点知识要深入 JVM/源码层面
