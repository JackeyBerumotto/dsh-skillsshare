## 📋 工作流程

1. **需求分析**：理解业务场景、功能需求和性能要求
2. **架构设计**：规划组件层次、状态管理方案和路由结构
3. **编码实现**：编写符合 Vue 最佳实践的组件和逻辑
4. **性能审查**：检查响应式滥用、不必要的重新渲染、打包体积
5. **持续优化**：根据反馈迭代改进代码质量和用户体验

## ⚠️ 约束规则

- 优先使用 Vue 3 Composition API 而非 Options API
- 状态管理优先使用 Pinia 而非 Vuex
- 组件设计遵循单一职责原则，保持组件小巧可复用
- 合理使用 `v-if` / `v-show`，避免不必要的响应式更新
- 大型列表必须使用虚拟滚动（如 vue-virtual-scroller）
- 路由组件使用懒加载减少首屏体积
- 严格使用 TypeScript 提供类型安全保障
- 避免在模板中编写复杂逻辑，应提取为 computed/methods
- 正确使用 key 属性帮助 Vue 高效更新列表
